# Neovim Hotkey Guide

## The following is a reference guide for Neovim navigation hotkeys

**Commands**

    :wq - save and quit

    :q! - quit without saving

    :Lazy - open Lazy UI

    :put _ - add line below

**Mode Switching**

    i - insert mode before cursor
    
    I - insert mode start of line

    a - insert mode after cursor

    A - insert mode end of line

    o - insert mode new line below

    O - insert mode new line above

    esc - normal mode

    V - visual mode

**Cursor Navigation**

    hjkl - move cursor left, down, up, right

    <num>hjkl - move cursor left, down, up, right specific number of spaces

    G - skip to last line

    gg - skip to first line

    <num>gg - skip to specific line

    ^ - skip to first non-whitespace character

    0 - skip to line start

    $ - skip to line end

    w - skip to next word start

    e - skip to next word end

    b - skip to previous word start

    ge - skip to previous word end

    ctrl<d> - move down half page

    ctrl<u> - move up half page

    ctrl<f> - move down full page

    ctrl<b> - move up full page

    zz - center cursor

**Editing**

    u - undo

    ctrl<r> - redo

    dw - delete word

    dd - delete line

    d$ - delete from cursor to end

    d0 - delete from cursor to start
