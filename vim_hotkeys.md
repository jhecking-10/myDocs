# Neovim Hotkey Guide

## The following is a reference guide for Neovim navigation hotkeys

### Commands

    - :wq (saves and quits Neovim)
    - :q! (quits Neovim *without* saving)
    - :Lazy (opens Lazy user interface)

### Navigation Hotkeys

    - a (switches to insert mode *after* cursor)
    - i (switches to insert mode *before* cursor)
    - esc (switches to normal mode)
    - G (moves cursor to *last* line of file)
    - gg (moves cursor to *first* line of file)
    - <num>gg (moves cursor to specified line)
    - dw (deletes word)
    - A (moves cursor to end of line and insert)
    - 0 (moves cursor to *start* of line)
    - $ (moves cursor to *end* of line)
    - o (adds line *below* and insert)
    - O (adds line *above* and insert)
    - w (jumps to *start* of next word)
    - e (jumps to *end* of next word)
    - b (jumps to *start* of previous word)
    - ge (jumps to *end* of previous word)
    - ^ (jumps to first non-whitespace character)
